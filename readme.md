Features:
Import/Export songs between engines without moving files (you can't export to codename for now)
Export songs as .fnfc
Remove/Rename notes in a easy way
Rename events
Make the major part of default events works in other engine without edit it
Create mod folders faster
Edit mod info with a UI

Future Features:
Import/Export Stages
Export Stages json/xml as script (lua, hx, hxs)
Import/Export Character
Work with Engine folders too
Generator for credits, stickerpack, weeks

REMEMBER the major part of the setting new you have set the working mod
Create a new Working mod:
1. Select File
2. New Mod Folder
3. Select Working engine
4. Select the Engine folder (the one with the .exe)
5. (Optional) Set the mod name
6. Create

Select Working mod:
1. Select File
2. Open a Mod Folder
3. There just select the mod folder which you are working
